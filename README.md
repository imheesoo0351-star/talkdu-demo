# talkdu demo (공개용)

고객 · 헬퍼 · 관리자 화면을 예시 계정과 가상 데이터로 둘러보는 공개 데모입니다.

## 열기

1. `index.html`을 엽니다. (GitHub Pages에서는 `/talkdu-demo/` )
2. **고객 화면** · **헬퍼 화면** · **관리자 데모** 중 하나를 고릅니다.

| 진입 | 경로 | 예시 |
|---|---|---|
| 고객 | `home.html?demo=customer` | 예이고객 |
| 헬퍼 | `home.html?demo=helper` | 길동헬퍼 (승인·공개 상태) |
| 관리자 | `admin/index.html?demo=admin` | 데모 운영자 |

## 포함

- 새 카테고리 이름(보이스챗, 커피챗, 크리에이터, 연애, 공부, 취미, 창업)
- 상세 CTA **지금 대화 요청**
- 관리자 신청 승인·반려, 코인 반환 (브라우저 로컬 저장소만)

## 보안

- 실제 비밀번호·API 키·운영 데이터는 넣지 않았습니다.
- 데모 입장은 쿼리(`?demo=`)와 로컬 세션만 사용합니다.
- 처리 결과는 이 브라우저의 `localStorage`에만 남습니다.
